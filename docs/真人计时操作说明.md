# 人工基线操作说明（V+.5，第二批 v2-islington-auto）

目的：取得同一质量标准下"纯人工"与"工具辅助"的每家分钟数，回答"工具是否真的省时间"。这不是销售触达，不联系任何餐厅，所有信息仅来自公开网页。

## 1 分组已冻结

- 批次 `v2-islington-auto`，50 家 Islington 餐厅（FSA 公开名录，2026-09-30 同步）。
- 用 `scripts/assign_arms.py` 以种子 20261002 分层随机分成 A 组（纯人工，25 家）与 B 组（工具辅助，25 家）；分层依据只用于平衡，不告知操作者。
- 文件在 `data/records/`（不提交）：`v2_arms.csv`（分组表）、`v2_human_worksheet.csv`（A 组）、`v2_tool_worksheet.csv`（B 组）。输入快照的 sha256 写在分组表内。

## 2 操作者与顺序

- 两组由同一人执行；先做 A 组，再做 B 组。理由：先用工具会把工具找到的官网和问题带进人工组。
- 做 A 组期间不打开工作台、不看 `v2_arms.csv` 的分层列、不看 B 组工作表。
- 在每张工作表填 `operator`（姓名或代号）与 `experience`（`none`＝首次做此类研究，`some`＝做过几次，`regular`＝日常工作）。
- 一次连续做完一家再做下一家；中途打断就在 `notes` 写明并把打断时间扣掉。

## 3 A 组：纯人工，每家四步各计时

只用搜索引擎、餐厅官网和公开页面；不用工作台，不用 Overture、Google Places 或任何抓取脚本。

1. **筛选**（`minutes_screen`）：判断是否目标类型（独立或小型集团堂食餐厅）。`screen_decision` 填 `candidate` 或 `excluded_chain / excluded_cafe / excluded_institution / excluded_community / excluded_other`，并写一句 `screen_reason`。判为排除就到此为止，后面各步填 0。
2. **官网**（`minutes_website`）：找到官网写 `website_url`，`website_how` 写 `search / fsa / social / none`。找不到写 `none`，进入下一步的结果为 `no_website`。
3. **菜单**（`minutes_menu`）：在官网找菜单，`menu_url` 写链接，`menu_format` 写 `pdf / html / image / none`，`menu_result` 写 `found / not_found / blocked / no_website`。
4. **问题**（`minutes_issues`）：按验证细则只看四类：低清、移动端阅读困难、文字溢出、价格或货币格式不一致。`issues_found` 每条一句事实描述，`issue_evidence` 写位置（页码、栏目、菜名或截图文件名）。不推断利润、过敏原和成分；缺双语不算问题；没有问题写 `none`，同样是有效结果。

`minutes_total` 为四步之和，另填 `started_at` 与 `finished_at`（当地时间，到分钟）。

## 4 B 组：工具辅助，每家六步各计时

登录工作台，打开 `workbench_path` 对应的线索详情页。

1. **复核预筛**（`minutes_screen_review`）：看工具的预筛标签与理由，同意就保留，不同意就改。
2. **官网**（`minutes_website`）：工具已补到官网就核对是否本店（同名同址），错的改掉；没补到就自己找，方法同 A 组。
3. **接入菜单**（`minutes_menu_attach`）：用"候选文件"面板一键接入或粘贴菜单 URL，等抓取结束。
4. **复核分析**（`minutes_analysis_review`）：文本 PDF/HTML 看规则引擎结果；图片菜单点"模型转录"，逐项核对菜名和价格。
5. **修正与确认**（`minutes_corrections`）：改错项、确认或否决问题、必要时人工新增问题；完成审核。
6. `retries` 记抓取或分析失败后重试的次数；`issues_confirmed` 记最终确认的问题数。

重试、等待和纠错时间都计入，不因为是工具的错就不算。

## 5 质量标准与汇总

- 两组用同一标准：验证细则第四节第 1～3 步；问题必须有位置证据。
- 完成后由第二个人（或事后由执行人本人换一天）抽查每组各 5 家的筛选与问题，记录不一致数。
- 汇总口径：每组的每家中位数与总分钟数、按四步/六步的分布、候选率、找到菜单率、每家确认问题数。样本各 25，只报观察差异，不称因果。
- 报告写入 `plan/validation-report-v2.md`；计时表原件留在 `data/records/`。

## 6 不要做的事

- 不打电话、不发消息、不填联系表单、不注册对方系统。
- 不把工具的官网结果抄给 A 组，也不把 A 组已找到的菜单预先塞进工作台。
- 不为了凑格式比例更换餐厅；找不到就如实记 `not_found`。
