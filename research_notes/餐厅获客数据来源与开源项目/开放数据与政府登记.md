# 欧洲（EU+UK）餐厅开放数据集与政府登记：免费底库 + 新开业信号（截至 2026-09-25）

> 本文件是对 `欧洲餐厅菜单获客系统可行性/数据来源.md` 的深化，不重复其中 Google Places / OSM 城市官网覆盖率等内容。
> 标注"实测"的数字为本次（2026-09-25）直接调用 API / DuckDB / 下载原始文件计算所得，脚本在会话 scratchpad，非二手资料。

## 1. Overture Maps Places：许可、字段、欧洲城市覆盖、查询方式、发布节奏

### Takeaway
Overture Places 是目前**免费、可商用、可落库**且联系字段最全的开放 POI 底库：许可为 CDLA Permissive 2.0（Meta/Microsoft/PinMeTo 等）+ Apache 2.0（Foursquare）+ CC0（AllThePlaces），**无 ODbL 共享义务**；字段含 websites / phones / emails / socials / confidence / basic_category / taxonomy / operating_status。实测 restaurant 数：都柏林 bbox 2,337、阿姆斯特丹 4,214、伦敦 26,892；**电话 89–93%、官网 80–84%、社媒（几乎全是 Facebook）80–93%、邮箱 36–53%**，远高于 OSM（伦敦官网 42%/邮箱 6%，旧笔记）。月度发布，最新 2026-09-23.0；2026-09 起 `categories` 字段已删除，需改用 `basic_category`/`taxonomy`。

### Cited Findings
- 许可：Places 主题按来源分别为 CDLA Permissive 2.0（Meta、Microsoft、PinMeTo、Krick、RenderSEO、DAC、BrightQuery）、Apache 2.0（Foursquare，需署名 "Data from Foursquare. Copyright 2024 Foursquare Labs, Inc."）、CC0 1.0（AllThePlaces）— [Overture Attribution](https://docs.overturemaps.org/attribution/)
- Places 主题"不包含 OpenStreetMap 数据，不承担 ODbL 的 share-alike 义务"；约 8,100 万条（2026-09），其中 Meta 约 5,900 万；月度发布 — [Overture Places Guide](https://docs.overturemaps.org/guides/places/)
- 2026-09 为大版本 schema 发布：`categories`（含 primary/alternate）被彻底移除，改用 `taxonomy`（primary/hierarchy/alternates）或 `basic_category`（约 280 个直观类别）；`operating_status` 默认值改为 null（此前为 open）；2026-08 版新增 164 万条被标为 open — [2026-09-23 release notes](https://docs.overturemaps.org/blog/2026/09/23/release-notes/)；[2026-08-19 release notes](https://docs.overturemaps.org/blog/2026/08/19/release-notes/)；[Places Guide](https://docs.overturemaps.org/guides/places/)
- 发布目录（STAC）：最新 release 为 `2026-09-23.0`，上一版 `2026-08-19.0`；places 共 16 个 zstd Parquet 分片，按空间分区（如 part-00006 覆盖 lon −76.5~−1.6 / lat 40.4~83.6，含爱尔兰；part-00007 覆盖 lon −1.6~6.3 / lat 40.4~62.7，含伦敦/阿姆斯特丹/巴黎）— [Overture STAC catalog](https://stac.overturemaps.org/catalog.json)（实测）
- 实测 schema（2026-09-23.0）：`id, geometry, confidence, websites[], emails[], socials[], phones[], brand, addresses[](freeform/locality/postcode/region/country), names, sources[](dataset/license/record_id/update_time/confidence…), operating_status, basic_category, taxonomy, version, bbox` — [S3 s3://overturemaps-us-west-2/release/2026-09-23.0/theme=places/type=place/](https://docs.overturemaps.org/guides/places/)（DuckDB DESCRIBE 实测）
- **实测：都柏林 bbox（lon −6.45~−6.04，lat 53.22~53.45）**，全部 place 40,614 条；`basic_category='restaurant'` 2,337 条（另 bar 1,064、cafe 618、fast_food_restaurant 243）：

- 查询方式：DuckDB `INSTALL httpfs; SET s3_region='us-west-2'; SELECT … FROM read_parquet('s3://overturemaps-us-west-2/release/<release>/theme=places/type=place/*')` 并以 `bbox.xmin/ymin` 过滤；亦可用 Azure Blob 镜像、`overturemaps` Python CLI、PMTiles（https://tiles.overturemaps.org/2026-09-23.0/places.pmtiles）— [Places Guide](https://docs.overturemaps.org/guides/places/)；[STAC places catalog](https://stac.overturemaps.org/2026-09-23.0/places/catalog.json)
- 第三方托管 API（overturemapsapi.com）已支持 taxonomy 与 operating status 查询 — [OpenSource Overture Maps API blog 2026-07-08](https://www.overturemapsapi.com/blog/2026/07/08/places-taxonomy-operating-status-and-divisions-admin-level)

### Inferences
- 实操建议：先用 STAC item 的 bbox 选出目标国家所在的 1–2 个分片，再直接读该分片的 HTTPS URL（比 `*` glob 快很多）；或一次性把爱尔兰/英国分片下载到本地再查。
- 邮箱 49% 来自 Meta（Facebook 页面）为主的数据，可能包含个人邮箱（gmail 等）；落库时应标记来源并做 GDPR/PECR 合规评估（见第 5 节）。
- `socials` 基本是 `https://www.facebook.com/<数字id>` 形式，Instagram 很少；Instagram 需另从官网/Facebook 页提取。
- confidence < 0.5 的记录多为已关闭或重复，建议底库阈值取 0.6–0.7。
- 覆盖对比：伦敦 Overture restaurant 26,892 vs OSM Greater London 9,113（旧笔记）≈ 3 倍；阿姆斯特丹 4,214 vs OSM 2,040；都柏林 2,337 vs OSM 都柏林市 873（边界不同，仅作量级参考）。FSA 伦敦各区 Restaurant/Cafe/Canteen 合计应在同一量级（威斯敏斯特一区即 3,530），未做全伦敦汇总。

### Gaps
- 未取得 Overture 官方公布的各国/各类别联系字段填充率；本节数字为单城实测。
- operating_status 在 2026-09 版中本 bbox 全为 null，无法用来识别新开/关闭。
- Overture 不提供"首次出现日期"字段；新开店只能通过相邻两个 release 的 GERS id 差分（bridge files / changelog）推断 — 本次未实测差分数量。

## 2. Foursquare Open Source Places（FSQ OS Places）

### Takeaway
FSQ OS Places：1 亿+ POI、Apache 2.0、可商用；字段含 tel / website / email / facebook_id / instagram / twitter / date_created / date_refreshed / date_closed / unresolved_flags，**`date_created` 可作为"新进入数据库"的弱信号**（非真实开业日）。2025 年起改为 Hugging Face 门控下载 + Places Portal（Iceberg 目录，DuckDB 可读）。本次无法免登录直接查询，**无公开的填充率统计**。Overture 已并入 Foursquare 数据（都柏林样本中 323/2,337 条带 Foursquare 来源），可先用 Overture 替代。

### Cited Findings
- 访问渠道：Places Portal（places.foursquare.com，注册后生成 token）、Hugging Face（foursquare/fsq-os-places，门控）、Snowflake Marketplace、S3 PMTiles `s3://fsq-os-places-us-east-1/release/vector-tiles/latest/fsq-os-places.pmtiles`；数据以 Iceberg 目录交付，支持 DuckDB/Spark/PyIceberg；许可 Apache 2.0 — [Access FSQ OS Places](https://docs.foursquare.com/data-products/docs/access-fsq-os-places)
- Hugging Face 数据集为门控，需同意分享联系信息；2025-09 版本已在新 Portal 提供 — [HF fsq-os-places](https://huggingface.co/datasets/foursquare/fsq-os-places)；[Foursquare Medium: Evolving FSQ OS Places](https://medium.com/@foursquare/evolving-fsq-os-places-fa7a3f5197cd)（403 未能直接读取，内容据搜索摘要）
- 规模与节奏：100M+ 全球 POI、22 个核心属性、计划月度更新、Apache 2.0 可商用（2024-11 发布）— [Simon Willison 2024-11-20](https://simonwillison.net/2024/Nov/20/foursquare-open-source-places/)；[opensource.foursquare.com/os-places](https://opensource.foursquare.com/os-places/)
- 字段定义：tel（本地格式电话）、website（POI 或连锁官网）、email（"Primary contact email address of organization, if available"）、facebook_id、instagram、twitter；date_created（进入数据库日期，"不一定是实际开业日"）、date_refreshed、date_closed（被标记关闭的日期）；unresolved_flags（closed/duplicate/delete/privatevenue/inappropriate/doesnt_exist）— [Places OS Data Schema](https://docs.foursquare.com/data-products/docs/places-os-data-schema)
- Overture 自 2026-03-18 起把 Foursquare 数据转换成 Overture schema 纳入 — [Overture Attribution](https://docs.overturemaps.org/attribution/)

### Inferences
- 新开业信号：按 `date_created` 最近 30–90 天 + `fsq_category_ids` 属餐厅 + `date_closed` 为空，可得"新进入 Foursquare 的餐厅"候选；需与 FSA/SIRENE 等官方信号交叉验证。
- 若 Overture 已含 FSQ 联系字段，则单独拉 FSQ OS 主要价值在于 `date_created`/`date_closed`/`instagram` 字段。

### Gaps
- FSQ OS Places 在欧洲的餐厅数量与 tel/website/email/instagram 填充率：未找到公开统计；需注册 Portal 后自行 DuckDB 计算（本次未注册，未实测）。
- 2025 年门控后是否仍严格月更：官方文档未写明具体节奏。

## 3. OpenStreetMap：社媒/联系标签填充率与提取工具

### Takeaway
OSM 全球 amenity=restaurant 中 phone 23.1%、website 20.1%、email 4.2%，**社媒标签极稀疏**：contact:instagram 1.66%、contact:facebook 2.88%、contact:whatsapp 0.07%；无开业日期（start_date 仅 0.6%）。OSM 适合作为交叉验证与补充，不适合作主底库；ODbL 公开分发衍生库需共享。

### Cited Findings
- taginfo 实测（全球 amenity=restaurant 组合标签数 / 占比）：phone 374,889（23.14%）；contact:phone 47,065（2.91%）；website 325,034（20.06%）；contact:website 33,129（2.04%）；email 67,571（4.17%）；contact:email 20,142（1.24%）；contact:instagram 26,825（1.66%）；contact:facebook 46,607（2.88%）；facebook 4,688（0.29%）；contact:whatsapp 1,135（0.07%）；start_date 9,684（0.6%）；check_date 153,612（9.48%）— [taginfo amenity=restaurant combinations](https://taginfo.openstreetmap.org/tags/amenity=restaurant#combinations)（2026-09-25 API 实测）
- 城市级官网/邮箱覆盖（柏林、阿姆斯特丹、伦敦、都柏林等）见旧笔记 — [旧笔记 数据来源.md 第 3 节](../欧洲餐厅菜单获客系统可行性/数据来源.md)
- 提取工具：Overpass（公共实例易限流）、Geofabrik 国家级 .pbf + osmium `tags-filter`、或 Overture base 主题之外自行处理 — [Geofabrik downloads](https://download.geofabrik.de/)；[osmium-tool](https://osmcode.org/osmium-tool/)

### Inferences
- 同城对比：都柏林邮箱 Overture 48.6% vs OSM 9.5%，伦敦 36.4% vs 6.0%，阿姆斯特丹 52.8% vs 17.4%；社媒 80–93% vs OSM <5%：联系字段层面 Overture 明显优于 OSM。
- OSM 的 `check_date` 可用来判断记录新鲜度；但不能提供新开业信号。

### Gaps
- 未对欧洲国家单独计算社媒标签占比（taginfo 为全球值）。

## 4. 食品卫生检查开放数据（覆盖所有食品经营者）与"新登记"信号

### Takeaway
**英国 FSA FHRS 是全欧最好的免费底库 + 新开业信号**：全英约 61.3 万食品经营者、每日更新、免注册 API；实测 Restaurant/Cafe/Canteen 141,026 家、Pub/bar 50,482、Takeaway 62,960。新注册的食品企业会先以 **"AwaitingInspection"（RatingDate=1901-01-01 占位）** 出现，是强"新开业/易主"信号（威斯敏斯特 91 家、曼彻斯特 497 家）。但 **FSA 不含电话/官网/邮箱**（Phone 字段实测 0 填充）。丹麦 Findsmiley 同样覆盖全部餐厅（23,353 家，含 CVR 号）。法国 Alim'confiance 只含已检查的机构；荷兰 NVWA 只公开已检查结果、无下载；爱尔兰 FSAI 与西班牙（餐厅豁免国家登记）没有公开完整名册；德国无全国性公开清单。

### Cited Findings
- FSA 开放数据：免费、无需注册；XML/JSON，按地方政府下载，每日更新；数据库共 612,802 家企业；API V2 文档 https://api.ratings.food.gov.uk/help；"NewRatingPending 为 true 表示地方政府已上传新数据但尚未发布"；"Awaiting Publication" 表示商家申诉中 — [FSA Open Data](https://ratings.food.gov.uk/open-data)
- FSA 使用条款："Terms and conditions apply"（FHRS 数据按 Open Government Licence 发布为通行做法，需在 food.gov.uk 条款页核对）— [FSA Open Data](https://ratings.food.gov.uk/open-data)
- **实测 FSA API（2026-09-25，extractDate 同日）**：业务类型 14 类；全英 Restaurant/Cafe/Canteen（BusinessTypeId=1）141,026；Pub/bar/nightclub（7843）50,482；Takeaway/sandwich shop（7844）62,960 — [FSA API V2](https://api.ratings.food.gov.uk/help)（实测）
- **实测 Westminster**（餐厅+酒吧+外卖 3,978 条，其中 Restaurant/Cafe/Canteen 3,530）：评级 5=2,639、4=624、3=313、2=180、**AwaitingInspection=91**、1=68、Exempt=47、0=14；**Manchester**（3,176 条，餐厅 1,968）：**AwaitingInspection=497**；AwaitingInspection 记录 RatingDate 为占位 1901-01-01；两地 Phone 字段非空 0 条 — [FSA API V2](https://api.ratings.food.gov.uk/help)（实测）
- FSA 字段（实测返回）：FHRSID、LocalAuthorityBusinessID、BusinessName、BusinessType、AddressLine1–4、PostCode、Phone（空）、RatingValue、RatingKey、RatingDate、NewRatingPending、geocode（经纬度）、LocalAuthorityName/Email、SchemeType（FHRS/苏格兰 FHIS）— 实测样例（Aberdeen 210 BISTRO）
- 丹麦 Findsmiley：Fødevarestyrelsen 每日发布 XML，"Open Public Data License with additional terms"，含 CVR、P 号、行业代码、名称地址、最近 4 次检查日期与笑脸等级 — [Virk Data 数据集](http://datahub.virk.dk/dataset/smiley-kontrolrapporter)；[OSM wiki DK](https://wiki.openstreetmap.org/wiki/Restauranter_og_Smiley_kontrolresultater)；[findsmiley.dk](https://www.findsmiley.dk/)
- **实测丹麦 Smiley XML**（60 MB，58,776 条）：Pixibranche="Restauranter, pizzeriaer, kantiner m.m." 23,353 条（"Serveringsvirksomhed - Restauranter m.v." 20,716；"Uden behandling" 2,637）；含 CVR 23,272（99.7%）；有经纬度 10,894；**尚无检查日期 677 条（新开信号）**；`reklame_beskyttelse=1`（拒绝广告保护）105 条 — [Smiley_xml.xml](https://www.foedevarestyrelsen.dk/Media/638212360788086849/Smiley_xml.xml)（实测）
- 法国 Alim'confiance：Licence Ouverte 2.0，CSV 42.7 MB / JSON 62.1 MB，每日更新；覆盖 2017-03-01 起**实际受检**的食品链机构（含餐厅），非全量名册 — [data.gouv.fr Alim'confiance](https://www.data.gouv.fr/fr/datasets/resultats-des-controles-officiels-sanitaires-dispositif-dinformation-alimconfiance/)
- 荷兰 NVWA：2025-07-01 起扩大公开范围（咖啡馆、食堂、餐饮等）；公开字段为商号、街道门牌、邮编、城市；仅已检查且在 KvK 登记为指定 SBI 的企业；FAQ 未提供下载/API — [NVWA 公告](https://www.nvwa.nl/actueel/nieuws/2025/06/19/aankondiging-nvwa-breidt-per-1-juli-openbaarmaking-inspectieresultaten-uit)；[NVWA FAQ](https://www.openbare-inspectieresultaten.nvwa.nl/veelgestelde-vragen)
- 爱尔兰 FSAI：食品企业须向 HSE 环境卫生办公室或农业部注册，但没有公开的完整名册；开放数据需邮件 opendata@fsai.ie 申请 — [FSAI Re-use of PSI](https://www.fsai.ie/re-use-of-public-sector-information)；[FSAI Register](https://www.fsai.ie/business-advice/starting-a-food-business/register)
- 西班牙：国家 RGSEAA 登记中，餐厅、酒吧等零售性质企业豁免 — [AESAN 搜索器](https://www.aesan.gob.es/AECOSAN/web/seguridad_alimentaria/subseccion/buscadores.htm)；[RD 191/2011](https://www.boe.es/buscar/act.php?id=BOE-A-2011-4293)。替代：马德里市"Censo de locales, sus actividades y terrazas de hostelería y restauración"（CSV/JSON/XML，历史自 2014-03）— [datos.madrid.es](https://datos.madrid.es/dataset/200085-0-censo-locales)

### Inferences
- 英国新开业信号做法：每日拉 FSA（或每日 XML），以 FHRSID 差分（新出现的 ID）+ RatingValue=AwaitingInspection 过滤 BusinessType 1/7843/7844，即"新登记的餐饮企业"；地址变化/名称变化可能指示易主。
- 英国经营者须在开业前至少 28 天向地方政府登记（通行规则，本次未取得原文），故 AwaitingInspection 名单中相当一部分是**开业前或刚开业**的店——正是菜单需求窗口。
- FSA 无联系字段 → 需用 名称+邮编 与 Overture 匹配补电话/官网/邮箱/社媒。
- 丹麦 Smiley 有 CVR，可与 CVR 注册库连接获取公司形态；`reklame_beskyttelse` 须作为外呼/邮件的屏蔽名单。

### Gaps
- FSA API 的 `ratingKey` 过滤参数实测对 AwaitingInspection 无效（返回全部 141,026），需下载后本地过滤；全英 AwaitingInspection 总数本次未汇总。
- FSA 条款页原文（是否 OGL v3）本次未抓取到。
- 意大利（ASL 地方卫生局）、德国（各州 Lebensmittelüberwachung）未找到公开全量名册。

## 5. 公司登记（区分个体/公司、董事姓名、新成立 SIC/NACE 56.10）与商用许可

### Takeaway
**英国 Companies House 免费 API 最好用**：Advanced Search 可按 SIC 56101/56102 + 成立日期筛选（单次最多 5,000），另有 Streaming API 实时推送公司/董事事件。实测活跃 SIC 56101 公司 54,910 家；2026 年 8 月新成立 56101 697 家、56102 919 家。**法国 SIRENE 免费且粒度到"机构（établissement）"并带创建日期**，是欧盟最强新开业信号（注意 2027-01-01 起 NAF 2025：56.10A→56.11G）。爱尔兰 CRO 2025 年起有 CC BY 4.0 开放数据（含 NACE）；比利时 KBO 每月免费 CSV；荷兰 KvK API 付费（€6.40/月 + €0.02/次）。区分个体/公司在英国至关重要：PECR 下公司可不经同意发 B2B 邮件，个体户需同意。

### Cited Findings
- **实测 Companies House 网页 Advanced Search**：SIC 56101 且 status=active → 54,910 条；2026-08-01~08-31 成立的 SIC 56101 → 697 条；同月 SIC 56102（unlicensed restaurants & cafes）→ 919 条 — [Companies House Advanced Search](https://find-and-update.company-information.service.gov.uk/advanced-search)（实测）
- API Advanced Company Search 参数：sic_codes、company_status、company_type、company_subtype、location、incorporated_from/to；size 1–5000；start_index 分页；需 API key — [CH Advanced company search spec](https://developer-specs.company-information.service.gov.uk/companies-house-public-data-api/reference/search/advanced-company-search)
- Streaming API：9 个流（company information、filing history、insolvency、charges、officers、PSC、disqualified officers、exemptions、PSC statements）；每账户最多 2 个并发连接，429 后需等 1 分钟 — [CH Streaming API overview](https://developer-specs.company-information.service.gov.uk/streaming-api/guides/overview)
- 免费 API key：developer.company-information.service.gov.uk 注册创建应用获取 — [UK Startup Flow](https://ukstartupflow.com/blog/uk-companies-house-api)（二手）
- PECR：可向任何法人（公司、苏格兰合伙、LLP、政府机构）发营销邮件无需同意；"Sole traders and some partnerships are treated as individuals"，需明确同意或软性同意 — [ICO Electronic mail marketing](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guide-to-pecr/electronic-and-telephone-marketing/electronic-mail-marketing/)
- 法国 SIRENE：Licence Ouverte 2.0；月度全量 stock（Parquet 675.7 MB / ZIP 929.4 MB），另有历史文件；API 每日更新，约 2,500 万企业、3,600 万机构；"diffusion partielle"（个人申请不公开）者姓名/地址/地理位置被遮蔽；使用须符合 GDPR 与 1978 年信息自由法 — [data.gouv.fr Base Sirene](https://www.data.gouv.fr/datasets/base-sirene-des-entreprises-et-de-leurs-etablissements-siren-siret)；[INSEE Sirene](https://www.insee.fr/fr/information/3591226)；[economie.gouv.fr](https://www.economie.gouv.fr/entreprises/gerer-son-entreprise-au-quotidien/gerer-sa-comptabilite-et-ses-demarches/sirene-le)
- SIRENE 字段 `dateCreationEtablissement`、`activitePrincipaleEtablissement` 可用；未来该字段值将只对应 NAF2025 — [Sirene API 变量文档](https://www.sirene.fr/static-resources/documentation/v_sommaire_311.htm)（据搜索摘要）
- NAF 2025：56.10A 传统餐饮 → 56.11G；56.10C 快餐 → 56.11J（快餐）/56.12Y（流动餐饮/餐车）；2027-01-01 正式生效，2026 年内 Sirene 预显示新代码 — [Legalvision](https://www.legalvision.fr/cabinet-formalites-juridiques/nouveaux-codes-naf-2025-verification/naf-2025-reforme-codes-ape/)；[INSEE NAF 2025](https://www.insee.fr/fr/information/8181066)

### Inferences
- 英国：每月约 1,600 家新成立的餐饮公司（56101+56102，2026-08 实测）；但**公司成立 ≠ 开店**（很多是空壳/控股），且注册地址常为会计师地址，必须与 FSA AwaitingInspection 名单按名称/邮编交叉。
- 英国个体户餐厅不在 Companies House；FSA 中无法直接区分个体与公司 → "在 CH 中匹配到 Ltd = 可发 B2B 邮件；匹配不到 = 视为可能个体户，仅电话/上门/信件"。
- 法国：SIRENE 按 `activitePrincipaleEtablissement IN (56.10A, 56.10C)`（2027 后 56.11G/56.11J）+ `dateCreationEtablissement` 近 30 天 + `etatAdministratifEtablissement='A'` 可直接得到**新开餐厅门店**（含地址、SIRET），这是英国没有的"门店级"信号；但无电话/邮箱，个人企业可能 diffusion partielle 遮蔽地址。
- 荷兰：KvK Zoeken 免费但据本次所见不支持按 SBI 批量筛选（需核实），批量名单要买 KvK 数据产品，性价比不如法/英。

### Gaps
- Companies House API 官方速率限制（通行认知为 600 次/5 分钟）本次未取得原文。
- 法国 SIRENE 对"商业勘探（prospection）"是否有明确使用限制：本次页面未见明确禁令；INSEE 另有"statut de diffusion"规则，需法务复核。
- 意大利 Registro Imprese（InfoCamere，ATECO 56.10.11）为付费，未核实价格；西班牙 Registro Mercantil 无免费批量 API（未找到来源）。
- 爱尔兰 CRO 数据是否含董事姓名、以及个体户（RBN 商号登记）是否在开放数据中：未核实。

## 6. 酒类/场所许可登记（英国地方议会 premises licence）作为新开业信号

### Takeaway
英国《2003 年许可法》第 8 条要求每个许可机关（约 300+ 地方议会）维护公开登记并在网站公示新申请（新场所许可、变更等），部分议会提供 CSV（如 Bexley、Broxtowe），但**无全国统一数据集**，格式各异，需按目标区逐个抓取。新场所许可申请（公示期 28 天）通常早于开业，是高质量"即将开业/易主"信号，尤其对有酒牌的正餐餐厅。

### Cited Findings
- 许可机关须依 Licensing Act 2003 第 8 条及附表 3、2005 年《登记（其他信息）条例》公开登记；须在网站公示新场所许可、变更、临时声明、俱乐部证书等申请 — [Harrow Licensing Public Register](https://www.harrow.gov.uk/licences/licensing-public-register)；[Eastleigh](https://www.eastleigh.gov.uk/business/council-services-for-businesses/licensing-permits-and-registration/alcohol-and-entertainment/public-registers-and-current-applications)
- CSV 下载示例：Bexley（各类许可登记 CSV）、Broxtowe（Licensed Premises Register / Premises Licence Applications CSV）— [Bexley](https://www.bexley.gov.uk/bexley-business-employment/business-services/licensing-and-permits/public-licensing-register/registers-you-can-download)；[Broxtowe](https://www.broxtowe.gov.uk/about-the-council/open-data-and-registers/public-registers/licensing-act-2003-public-register)
- 其他：RBKC、Richmond 在线公示受理中的申请 — [RBKC](https://www.rbkc.gov.uk/licensing/licensingapplications/default.aspx)；[Richmond](https://www.richmond.gov.uk/licensing_applications_received)
- 伦敦数据中心仅提供按区汇总的场所许可数量，非明细 — [London Datastore](https://data.london.gov.uk/dataset/number-premises-licences-and-club-premises-certificates)

### Inferences
- 试点城市（如伦敦几个区、都柏林之外）可写小爬虫每周抓"applications received"页；许可"转让（transfer）"与"指定场所主管变更（DPS variation）"是**易主信号**。
- 爱尔兰酒牌由法院/税务局发放，未见同类开放登记（未核实）。

### Gaps
- 未统计英国提供 CSV/开放数据的议会比例；未核实 Westminster/Camden 等大区是否有机器可读格式。

## 7. 试点国家的最佳免费组合（UK/IE vs FR vs NL）

### Takeaway
**英国是最佳试点**：FSA（全量名册+每日新登记信号，免费）+ Overture（电话/官网/邮箱/社媒补全，免费可存）+ Companies House（公司 vs 个体、董事姓名、新成立，免费）+ 议会许可登记（新开/易主）。**法国次之**：SIRENE 门店级新开信号最强且免费，但联系字段完全依赖 Overture/官网，且法语市场与 GDPR/CNIL 更严格。**爱尔兰**缺少食品企业公开名册，只能用 Overture + CRO。**荷兰**无免费全量名册（NVWA 不可下载、KvK 付费），但 OSM/Overture 官网覆盖率高，可纯 POI 驱动。

### Cited Findings
- 英国：FSA 餐厅类 141,026 + 酒吧 50,482 + 外卖 62,960（实测）— [FSA API](https://api.ratings.food.gov.uk/help)；CH 活跃 56101 公司 54,910、月新成立约 1,616（56101+56102，2026-08，实测）— [CH Advanced Search](https://find-and-update.company-information.service.gov.uk/advanced-search)；PECR 公司/个体差异 — [ICO](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guide-to-pecr/electronic-and-telephone-marketing/electronic-mail-marketing/)
- 爱尔兰：Overture 都柏林 2,337 家 restaurant，电话 91%/官网 80%/邮箱 49%（实测）；荷兰：阿姆斯特丹 4,214 家，电话 89%/官网 81%/邮箱 53%（实测）；英国：伦敦 26,892 家，电话 93%/官网 84%/邮箱 36%（实测）；CRO 开放数据 CC BY 4.0 含 NACE — [CRO](https://cro.ie/the-companies-registration-office-cro-announces-the-launch-of-new-open-data-portal/)；FSAI 无公开名册 — [FSAI](https://www.fsai.ie/re-use-of-public-sector-information)
- 法国：SIRENE Licence Ouverte、日更 API、机构级创建日期 — [data.gouv.fr](https://www.data.gouv.fr/datasets/base-sirene-des-entreprises-et-de-leurs-etablissements-siren-siret)；Alim'confiance 仅受检机构 — [data.gouv.fr](https://www.data.gouv.fr/fr/datasets/resultats-des-controles-officiels-sanitaires-dispositif-dinformation-alimconfiance/)
- 荷兰：KvK €0.02/次 — [KVK pricing](https://developers.kvk.nl/nl/pricing)；NVWA 无下载 — [NVWA FAQ](https://www.openbare-inspectieresultaten.nvwa.nl/veelgestelde-vragen)；OSM 阿姆斯特丹官网 66%（旧笔记）

### Inferences
- 推荐英国管线：
  1. **底库**：FSA 全量（BusinessType 1/7843/7844）→ 以 名称模糊匹配 + 邮编 + 50 m 距离 与 Overture（confidence≥0.6）匹配，补 phones/websites/emails/socials；
  2. **法人/合规分层**：用 FSA 名称+邮编 查 Companies House（SIC 5610x），匹配到 Ltd → 可 B2B 邮件；否则按个体户处理；
  3. **新开业信号**（每日/每周）：FSA 新 FHRSID & AwaitingInspection；CH 新成立 SIC 56101/56102（Streaming 或 Advanced Search incorporated_from=昨天）；议会新场所许可申请/转让；
  4. **补官网邮箱**：对 Overture 缺邮箱者抓官网（见旧笔记第 6 节）。
- 成本：以上数据源全部免费（仅 CH/FSA 需要自建调用）；Overture 单国查询可本地一次性下载分片（~GB 级）。
- 法国作为第二市场：SIRENE 新机构（56.10A/C，2027 起 56.11G/J/56.12Y）每日增量 + Overture 补联系方式；注意 diffusion partielle 与 CNIL 对 B2B 冷邮件（需告知+可退订，对个人企业更严）。

### Gaps
- 未实测 FSA ↔ Overture 的实际匹配率（建议试点抽样 500 家）。
- 未量化 AwaitingInspection 记录中"真正新开"与"长期未检查老店"的比例（曼彻斯特 497 家偏高，可能积压）。
