## 问题 1：餐厅发现 + 网站/电话/评分——Google Maps 抓取器 vs 开放 POI 数据

### Takeaway
gosom/google-maps-scraper（MIT、Go、6.1k stars、昨日仍在推送）是目前最成熟、可自托管、且自带"从官网抽邮箱"的 Google Maps 抓取器，但抓取 Google Maps 与 Google Maps Platform 条款明确冲突；合规底座应优先用 Overture Places（CDLA-Permissive-2.0/Apache-2.0，含网站/电话/邮箱/社媒字段、月更）+ Foursquare OS Places（Apache-2.0）+ OSM（ODbL），Google 仅用官方 Places API 取评分并只长期保存 place_id。

### Inferences
- 推荐"开放数据打底 + Google 官方 API 补评分"：Overture（含 Foursquare 部分贡献）+ OSM（`amenity=restaurant/cafe/bar`、`website`、`phone`、`contact:*` 标签）合并去重，得到候选名单与网站；评分/评论数通过 Places API (New) 获取，只长期存 place_id，展示时实时拉取。
- gosom 适合作为内部评估/对照基线（测覆盖率差距），若交付给商业客户，抓取 Google Maps 的合同与 ToS 风险应由客户书面知情或完全避免；欧盟还叠加 GDPR（自然人店主的邮箱/电话属于个人数据）。
- OSM 数据为 ODbL：若对外分发"衍生数据库"需 share-alike，Overture 则明确无此义务（据 Overture 文档），商业交付更省心。
- omkarcloud 实际是"开源外壳 + 付费 SaaS"，不适合作为可复用代码依赖。

### Gaps
- Google Maps Platform ToS 具体条款编号（如 3.2.3）本次抓取页面被截断，未能逐字核对编号；上述条款内容来自 Google 官方条款页的搜索摘要。
- Overture / Foursquare 在欧洲具体城市的餐厅覆盖率、网站/电话/邮箱字段填充率未找到公开统计，需要自测（建议抽 1–2 个城市对比 gosom 结果）。
- 未找到官方 `foursquare/fsq-os-places` 示例仓库（API 返回 404），Foursquare 示例主要在其文档站。

## 问题 2：官网爬取与联系方式抽取（邮箱/电话/WhatsApp/Instagram/Facebook/联系表单）+ 邮箱验证

### Takeaway
没有一个成熟的"现成联系人抽取器"值得直接依赖（相关小仓库 stars 个位数或已停更），最佳做法是组合：Crawl4AI 或 Crawlee-Python 做 3–10 页浅爬（首页/contact/impressum/about/menu），extruct 抽 schema.org JSON-LD（Restaurant 的 telephone/email/sameAs/menu/hasMenu），python-phonenumbers 规范化电话，自写正则识别 mailto/wa.me/instagram/facebook 与 `<form>`，email-validator 做语法+MX 校验；reacher 的 SMTP 验证是 AGPL/商业双授权，需谨慎。

- 欧洲特有：德/奥/瑞站点的 Impressum 页、意大利 P.IVA、法国 mentions légales 页通常含邮箱/电话/公司主体，应作为爬取优先路径。
- Firecrawl 功能强但 AGPL + 自托管组件重（6 个服务），且反爬能力不在开源版默认栈中；作为商业交付依赖不如 Crawl4AI（Apache-2.0）。
- 邮箱验证：先用 email-validator（语法+MX），SMTP 探测若需要，reacher 仅以独立服务网络调用方式使用也仍需评估 AGPL 网络条款，最稳妥是购买商业许可或只做 MX 级校验；SMTP 探测在很多云主机 25 端口被封。

### Gaps
- 未找到维护良好、专门抽取 WhatsApp 号码/链接的开源库；需自写规则。
- 未找到针对欧洲餐厅站点联系人抽取准确率的公开基准。

### Inferences
- AGPL/GPL 影响：Firecrawl、PyMuPDF、nodriver、reacher(开源版) 为 AGPL，若修改并以网络服务形式向客户提供，需开放对应源码；作为独立未修改服务调用的边界存在法律解释空间，商业交付建议避开或购买商业许可。GPL 的 theHarvester、undetected-chromedriver、gaspa93 在分发时有传染性。
- 整体推荐技术栈（Python 单语言）：Overture/OSM → 去重合并 → Places API 取评分（仅存 place_id）→ crawl4ai/crawlee+playwright 浅爬官网 → extruct + 正则 + phonenumbers → email-validator → docling/PaddleOCR 菜单。

### Gaps
- GitHub 搜索 API 未认证限流，"foursquare"之外的部分查询（菜单抽取、社交链接等）返回过一次 rate limit 错误，候选覆盖可能不完整；建议用带 token 的 `gh` 再补扫一次。
- 未对各项目做实际运行测试，性能/准确率数据均为 README 自述。
