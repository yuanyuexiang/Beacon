# 客户沟通工作台改造

2026-11-10，用户批准实施。以客户为入口，以渠道＋具体联系方式组织会话。

## 开发地图

- [x] 1. 数据：独立联系人草稿、连续消息投影、精确回复关联、按用户保存已读位置。
- [x] 2. 页面：客户列表／会话与持续编辑器／可收起资料；消息内查看执行状态和截图。
- [x] 3. 闭环：同一联系人可再次发送、人工回复回填、未关联历史记录、AI 跟进与本地回归。

## 验收

同客户两个邮箱与多个社媒历史、草稿互不覆盖；未回复可继续写新消息；最终确认幂等；失败及未知结果原样保留，不冒充发送成功。明确回复按联系人归档，无法确定的留在未关联记录。已读位置按操作者保存，读取页面不标记尚未展示的新消息。普通用户权限隔离沿用现有门店归属。仅本地测试，不自动提交、部署或真实发送。

迁移需同步 compatibility.json；旧任务和内容保留，不复制旧发送记录。
