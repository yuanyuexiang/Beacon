# 手机执行渠道实施计划

日期：2026-11-05。用户授权扩展现有 Beacon；首轮 WhatsApp，React Native + Expo，原生模块仅负责 Android 执行。方案依据：[手机执行渠道方案](../docs/手机执行渠道方案.md)。

## 开发顺序与验收

- [x] M1 后端：设备一次性配对、设备凭据、账号绑定、既有任务确认入队、租约、发送前复核、幂等结果、取消与未知结果；迁移及兼容声明一起更新。
- [x] M2 手机开发：Expo 页面（工作台／记录／设备）、原生权限检查及 WhatsApp 适配；原生执行日志先落盘，异常暂停，不自动重复发送。APK 已构建，实机验收单独列入 M4。
- [x] M3 网页：设置新增手机渠道，任务页提供手机预览确认与结果入口；复用任务、文案、归属及抑制机制。
- [x] M4 首轮验证：后端权限／重复请求／断网与取消回归，Web／移动类型检查，原生 APK 构建；本人 WhatsApp 会话的真实发送与回填通过。实测范围与后续未验收项如下。

首轮执行模式为用户主动开启会话、逐条核对目标的手机执行；先验证独立 APK 后再开放无人值守领取。FB／INS 适配与回复自动巡检列入后续轮次，首轮不把 USB 验证宣称为独立 App 验收。

## 实施约定

设备绑定到操作者；配对码短时单次使用，数据库仅保存凭据摘要。设备不能借任意 lead_id 读取客户资料。任务保留既有确认文案 hash；发送前重新核对权限、内容、拒收及任务状态。发送开始后失联标为待核对，不自动重派。实际发送和取消存在竞态，如实回填。不得因 UI 打开或文字填入即记已发送。

2026-11-05 用户要求测试阶段简化配对：改为随机 6 位数字，5 分钟有效且单次使用；设备长期凭据仍用高强度随机值。上线前重新评估配对机制。手机使用数字键盘，旧长配对码仍可由后端识别。

网页维持既有红金主题。按钮 loading 按操作隔离。设备页只显示用户需要的连接、账号、权限及任务结果，不暴露内部协议字段。

本轮仅本地实施；用户自行提交推送。真实测试只使用用户明确指定的自有会话和内容。

## 已运行验证

- API 最终全量 634 项通过（含手机专项 11 项）；Ruff、格式和 mypy 通过。修复了原有名单摘要变量类型冲突、历史测试夹具类型和旧摘要断言／迁移格式问题。
- Web 30 项测试、类型检查和生产构建通过；手机设置页模拟回归通过并检查宽窄屏截图。
- Expo TypeScript 检查、Android JS bundle 导出及原生模块 autolinking 发现通过。
- 部署配置验证与 18 项部署测试通过；未推送或触发云端部署。
- 原生 Kotlin 模块与独立 arm64 release APK 构建通过（603 个 Gradle 任务，含 AAR 检查和 release lint）；APK 位于 `data/devchecks/mobile/Beacon-mobile-0.1.0.apk`，约 22 MB，内部调试签名。
- APK 已安装到 Xiaomi 14 Pro（Android 16）；工作台／记录／配对页面已实机查看，短码配对和无障碍服务连接通过。
- 配对体验修复：键盘打开时点击按钮仍会执行；失败弹窗明确提示；增加 USB 地址快捷填入，说明电脑 IP 的 HTTP 地址不支持。类型检查、APK 重建和覆盖安装通过。
- 用户已完成配对。无障碍检查发现 Mobile MCP 的 UiAutomation 会话压制普通服务，退出该调试会话后，Android Bound services 已确认连接 Beacon 手机执行；执行期间不再调用占用该通道的 UI 检查工具。
- 首次本人号码实测：确认入队 → 手机领取 → WhatsApp 按号码跳转提示“无法连接” → 设备回填 failed；发送前检查未进入，未点击发送。失败任务与记录保留。
- 第二次实测仍在号码核验前失败，WhatsApp 启动回到聊天列表，未点击发送。已补充复用正确聊天：恢复 WhatsApp 后匹配唯一近期号码或明确“你”标识的本人会话，进入后仍核对聊天标题／本人标识；不匹配才调用号码链接。两次失败记录均保留，不自动重派。
- 第三次实测成功：用户在当前会话明确授权本人号码，手机 App 发送一条“Beacon 手机执行测试，请忽略，无需回复。”。执行记录 `2321cb97-f904-4746-b753-6d928dc908a5` 为 `sent`，任务 `f0b435fa-eac3-477f-baca-5e01f1d01338` 为 `sent_manual`；具有真实发送前检查时间、设备观察结果及回填时间，用户确认收到该文字。测试流程中未向餐厅发送消息。
- 本地 API 已运行并完成 `d180a0010001` 迁移；网页镜像已更新，`/settings?section=mobile` 返回正常。云端未改动。

构建工具链：Expo 58 使用 compileSdk 37／targetSdk 36，参见 [Expo SDK 官方兼容表](https://docs.expo.dev/versions/latest/)。初次 APK 检查发现本机 SDK 36 不满足预编译 Expo 依赖要求，已修正项目配置并安装校验过的官方 SDK 37，不跳过 AAR 兼容检查。

首版使用一个业务任务对应一份手机执行记录。失败／取消保留记录，可切回人工执行；未知结果核对后解除设备阻塞，不提供自动重发。后续如增加同任务重试，须引入独立尝试历史和旧尝试迟到结果归档，不覆盖现有记录。

本次实机验收范围是本人会话的一条消息。陌生号码查询、其他联系人界面、真实断网／锁屏／进程终止场景、远程 HTTPS 连接、多账号及批量执行仍需后续验证；不能把本人会话通过推广为任意餐厅可稳定自动发送。
